# Jt Bolsas Femininas

Vitrine institucional responsiva da Jt Bolsas Femininas, com direcionamento para o catálogo oficial do WhatsApp e o Instagram da marca.

## Executar localmente

Como o projeto é estático, basta abrir `index.html` no navegador. Para uma experiência mais próxima do deploy, use qualquer servidor local, por exemplo:

```bash
python3 -m http.server 8080
```

Depois, acesse `http://localhost:8080`.

## Publicar

O projeto pode ser publicado diretamente em GitHub Pages, Netlify ou Vercel. Não há etapa de build nem variáveis de ambiente necessárias.

As imagens dos cards são ilustrativas e os cards direcionam ao catálogo oficial, onde ficam os modelos, detalhes e preços disponíveis.
